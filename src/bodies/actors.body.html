One call, normalized JSON

Same auth, same envelope across every actor. Here's the Google Maps actor.

REQUEST
curl https://api.ollagraph.com/v1/actors/google-maps \
  -H "Authorization: Bearer osk_…" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://maps.google.com/?cid=1234567890"
  }'
RESPONSE
{
  "status": "success",
  "url": "https://maps.google.com/?cid=1234567890",
  "time_ms": 1240,
  "data": {
    "name": "Blue Bottle Coffee",
    "address": "66 Mint St, San Francisco, CA",
    "rating": 4.5,
    "review_count": 1084,
    "phone": "+1 510-653-3394",
    "category": "Coffee shop"
  }
}
